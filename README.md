# Huancayo Tennis Hub

Aplicación web para gestión de torneos, ranking ELO y matchmaking en Huancayo.

## Estructura
- Creada con Vite + React
- Base de datos: Supabase (PostgreSQL)
- Estilos: Tailwind CSS (Paleta Terracota / Roland Garros)

## Despliegue en Vercel
1. Sube esta carpeta o contenido a GitHub.
2. Importa el repositorio en Vercel.
3. Vercel detectará la configuración automáticamente (Vite).
4. Haz clic en Deploy.
